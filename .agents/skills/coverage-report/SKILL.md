# coverage-report

Write professional script coverage in the format used by studios, agencies, and production companies.

## Coverage sections

1. **Title / Author / Genre / Format / Pages**
2. **Logline** — one sentence, present tense, protagonist + want + obstacle + stakes
3. **Synopsis** — 400–600 words, three-act summary, major plot turns only, no scene-by-scene
4. **Character breakdown**
   - Protagonist: want, need, arc
   - Antagonist / opposition: function and credibility
   - Supporting: notable strengths or weaknesses
5. **Analysis grid** (rate each 1–5: Excellent / Good / Fair / Poor / Very Poor)

   | Element | Rating | Notes |
   |---|---|---|
   | Concept | | |
   | Structure | | |
   | Dialogue | | |
   | Characters | | |
   | Originality | | |
   | Marketability | | |

6. **Comments** — 200–400 words of specific, constructive notes. Lead with strengths, then address core weaknesses, then give 2–3 actionable recommendations.
7. **Recommendation**: PASS / CONSIDER / RECOMMEND (with brief justification)

## Tone guidelines

- Write as a professional reader: specific, evidence-based, not personal.
- Cite page numbers or scene references where possible.
- Avoid vague praise ("great characters") — name what works and why.
- Be direct about fundamental flaws; development notes exist to improve the work.

## Workflow

1. Ask the user to share the script text, a detailed description, or the sections they want covered.
2. If only a partial script is provided, note the scope of the coverage.
3. Produce the full coverage report in order.
4. Offer a one-page "executive summary" version on request.
