# scene-outline

Outline scenes for a screenplay with structured action beats, character arcs, and dramatic purpose.

## What this skill produces

For each scene:
- **Scene heading** (INT./EXT., location, time of day)
- **Dramatic purpose** — what must change for the story to move forward
- **Action beats** — 3–6 bullet points describing what physically happens
- **Character arc moment** — how this scene advances or tests the protagonist's want/need
- **Emotional turn** — where the scene starts emotionally vs. where it ends
- **Scene-ending image or button** — the last thing the audience sees/hears

## Workflow

1. Ask the user for: logline or concept, genre, approximate page count / episode count, and any character notes they have.
2. Identify act structure (three-act, five-act, pilot structure, etc.) appropriate to format.
3. Produce a scene-by-scene outline, numbered, in order.
4. Flag scenes that are dramatically inert or redundant and suggest consolidation.
5. Offer to expand any scene into a full beat sheet on request.

## Output format

```
SCENE 1 — INT. DINER - NIGHT
Purpose: Establish protagonist's stasis world and want.
Beats:
  - Maya nurses cold coffee, scanning a job board on her phone.
  - Regulars ignore her. She's invisible here.
  - A stranger drops a business card on her table and walks out.
Char arc: Maya's hunger for escape is present but passive.
Emotional turn: Invisible → Noticed (ambiguously).
Button: She flips the card. We can't read it yet.
```

## Tips

- Keep each scene outline to ~150 words max; depth is for the beat sheet phase.
- Every scene should change the value charge (positive → negative or vice versa).
- If the user has an existing outline, critique it before rewriting.

## Live Data Sources

- **Save the Cat beat sheet framework** — Blake Snyder's publicly documented 15-beat structure used widely in Hollywood development
- **Hero's Journey academic resources** — Joseph Campbell's monomyth framework (public domain scholarship)
- **IMDB plot structure data** — public IMDB API for referencing real film plot summaries and structure patterns
- **TVTropes story patterns** — tvtropes.org community-documented narrative patterns and genre conventions (public)
